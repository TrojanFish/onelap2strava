如何获取 Strava Cookie？

1

在电脑浏览器打开 Strava

使用 Chrome 或 Edge 访问 strava.com 并完成登录。

2

打开开发者工具 (F12)

按 F12，切换到 Application (应用) 标签页。

3

复制 `_strava4_session` Cookie

展开左侧 Storage -> Cookies -> `https://www.strava.com`，双击复制 `_strava4_session` 的 Value 字段值。

提示：Strava 会话 Cookie 有效期较长（通常数周）。若提示失效，重新提取并更新保存即可。

如何获取 Strava Refresh Token？

1

第一步：浏览器授权获取 Code

打开 Strava 设置 -> 我的 API 应用程序 获取客户 ID (Client ID)。在浏览器地址栏输入以下网址授权：

https://www.strava.com/oauth/authorize?client_id=你的客户ID&response_type=code&redirect_uri=http://localhost&approval_prompt=force&scope=read,activity:write,activity:read_all

访问后点击“授权”，浏览器重定向至 localhost，从地址栏复制 code= 后面的代码（例：7754cccfa083...）。

2

第二步：换取 Refresh Token

可以直接使用左侧表单的 **【网页一键 Token 换取助手】** 自动换取，或在电脑终端执行 curl 命令：

curl -X POST https://www.strava.com/oauth/token \
  -F client_id=客户ID \
  -F client_secret=客户端密钥 \
  -F code=第一步获取的code \
  -F grant_type=authorization_code

⚠️ 终端输入时注意结尾“\”之前都有一个空格。

3

第三步：复制 Refresh Token

在返回的 JSON 结果中复制 refresh_token 的值（例：b5c269df0e6616651a16dbbb17dbea7a740c45dc），填入左侧表单保存即可！
